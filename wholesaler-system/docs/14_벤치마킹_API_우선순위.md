# 대내외 통합 채권관리 시스템 벤치마킹과 API 도입 우선순위

조사일 2026-11-05. 글로벌 기업용 채권·여신 관리 시스템(SAP, Oracle, HighRadius, Gaviti)의 공개 자료와 국내 공공·상용 API 를 조사해, 현 시스템(0.7.0-weekly)과 비교한 결과입니다.

## 1. 벤치마킹 — 대기업·외국 기업 시스템이 공통으로 갖춘 것

| 기능 | SAP FSCM Collections | Oracle Advanced Collections | HighRadius / Gaviti | 현 시스템 | 평가 |
|---|---|---|---|---|---|
| 조기경보(지표 임계값 → 위험 알림) | ○ | ○ | ○ (AI 점수) | **○** S01~S07 + 체크리스트 | 동등. 기준값이 [가정]인 점만 차이 |
| 담당자 작업목록(워크리스트) | ○ | ○ | ○ | **○** 담당자 업무·확인 기한 SLA | 동등 |
| 결제약속(Promise to Pay) 이행 추적 | ○ (약속 시 독촉 자동 보류) | ○ (약속 작업·이행 점검) | ○ | **△** 결제계획을 글로만 기록, 약속일·금액 이행 여부 자동 대조 없음 | **보완 1순위** |
| 독촉(Dunning) 단계·이력 자동화 | ○ (단계별 자동 발송) | ○ (XML Publisher 자동 발송·이력) | ○ (메일 템플릿) | **△** 조치 유형·이력은 있으나 독촉장 생성·발송 자동화 없음 | 보완 2순위 (내부 규정 서식 확인 후) |
| 포트폴리오 집중도 분석 | ○ | ○ | ○ (집중 위험·한도 사용 추세) | **△** 4분면·한도 사용률은 있음, "상위 N명 미수 집중도" 지표 없음 | 보완 3순위 (분산 역량 강화 목적과 직결) |
| 회수(현금) 예측 | △ | △ | ○ (AI 예측) | ✕ | 자료(입금 내역) 확보 후 검토 |
| 분쟁(Dispute) 관리 | ○ | ○ | ○ | ✕ | 경매 정산 구조상 해당성 낮음 — 도입 불필요 |
| 외부 신용정보 연동 | ○ | ○ | ○ (신용평가사 연동) | ✕ (NICE 점수는 정책상 미적재) | 아래 API 표 참고 |

요약: **탐지와 작업 배분은 대기업 시스템과 같은 골격**이고, 차이는 "탐지 이후"에 있습니다. 결제약속 이행 추적, 독촉 이력 표준화, 미수 집중도 지표가 보완 대상입니다.

## 2. 기능 보완 우선순위 (코드 추가, API 불필요)

| 순위 | 보완 | 내용 | 효과 | 공수 |
|---|---|---|---|---|
| 1 | 결제약속 이행 추적 | 동향보고의 결제계획을 약속일·약속금액 구조로 받고, 입금 자료가 들어오면 이행/불이행을 자동 판정 → 불이행 시 신호 | 약속 어김(체크리스트 2번 항목)의 자동화 | 중 |
| 2 | 가져오기 실패 알림 | 08시 알림 메일에 "가져오기 실패 N건" 포함 (13번 문서 권장사항) | 파일 제출 누락 방지 | 소 |
| 3 | 미수 집중도 지표 | 상위 5·10명 미수 비중, 한 명 비중 상한 경고 | "분산 역량 강화" 목적의 직접 지표 | 소 |
| 4 | 독촉 이력 표준화 | 조치 유형에 독촉 차수(1·2·3차)와 발송일 구조화, 서식 연결 | 법적 조치 전 단계 증빙 | 중 |

## 3. 추가하면 좋을 API — 우선순위 표

Apps Script(UrlFetchApp)에서 바로 호출 가능 여부와 비용·법적 절차를 기준으로 정렬했습니다.

| 순위 | API | 제공처 / 비용 | 무엇이 좋아지나 (연결 지점) | 도입 난이도 | 비고 |
|---|---|---|---|---|---|
| **1** | 사업자등록 상태조회 (휴·폐업) | 국세청, 공공데이터포털 data.go.kr (15081808) / **무료** | 사업자번호로 계속(01)·휴업(02)·폐업(03) 자동 확인 → 영업 상태 자동 갱신 + 신규 신호 "휴폐업 감지". 체크리스트 7·8번(대표자·신용)의 전산 보조 | **하** (REST·JSON, 키 발급만. 하루 1회 전체 조회면 충분) | 사업자번호 열을 기초자료에 추가해야 함 [확인 필요]. 설치본 매니페스트에 외부 호출 권한 1줄 추가 필요 |
| **2** | 전국 공영도매시장 정산가격 정보 | 농림축산식품부·aT, data.go.kr (15141809) / **무료** | 전국·인근 도매시장의 품목별 정산 물량·금액 → "다른 시장으로 거래 이탈"(체크리스트 10번) 참고 지표, 시장 대비 증감 비교의 외부 기준 | 하~중 (자료량 많아 품목·시장 필터 필요) | 중도매인 단위가 아닌 시장·법인 단위 — 참고 지표로만 |
| **3** | 온비드 공매정보 | 캠코, 공공데이터포털 / **무료** | 담보 부동산의 공매 공고 감지 → 담보 가치 훼손 조기 인지 (신호 S06 보강) | 중 (주소·소유자 매칭의 한계, 오탐 관리 필요) | 법원 **경매**는 공식 OPEN API 없음(아래 6) |
| **4** | KAMIS 농산물 가격 | aT / **무료** | 취급 품목 가격 급락기 식별 → 실적 감소 신호(S04)의 "시황 탓/개별 탓" 구분 보조 | 하 | 판정에 자동 연결하지 않고 참고 표시만 |
| **5** | 기업·사업자 신용정보 (NICE BizAPI, KODATA KOapinet) | NICE평가정보·한국평가데이터 / **유료(계약)** | 타 기관 연체·세금 체납 등(체크리스트 8번) 전산 확인 | 상 (신용정보법 절차, 조직 계약·승인 필수) | **개인 신용점수 미적재 원칙 유지**. 조직 차원 결정 후에만 |
| **6** | 법원경매 사건검색 (CODEF 등 중개) | 민간 중개 / **유료** | 담보 부동산 경매 개시 감지 | 상 | 대법원 공식 OPEN API 부재 확인(공공데이터포털 답변). 3순위 온비드로 공매부터 |
| 보류 | 오픈뱅킹(입금 내역) | 금융결제원 / 유료·심사 | 미수금 입금 자동 수집 | 상 | 내부 정산 시스템 추출(AR_BAL·RECEIPT 형식)이 먼저. 그게 더 정확하고 무료 |

### 권장 도입 순서
1. **지금**: 국세청 휴폐업 조회(1순위) — 무료·쉬움·효과 큼. 사업자번호 확보가 선행 과제.
2. **미수 자료 확보 후**: 결제약속 이행 추적(기능 1순위)과 묶어서.
3. **분기 단위 검토**: 도매시장 정산 API(2)·온비드(3)는 참고 지표로 붙이고, 유료 신용정보(5·6)는 조직 승인이 나면.
