# 남은 보완 과제 통합 우선순위

작성일 2026-11-05. 벤치마킹(문서 14)·프로세스 점검(문서 13)·실자료 적재 결과(문서 11의 2-1)에서 나온 과제 중 **아직 적용하지 않은 것**을 한 표로 모았습니다. 이미 적용한 가져오기 실패 알림과 독촉 이력 표준화는 제외했습니다.

## 읽는 법
- **1번이 전부의 선행 과제**입니다. 1번이 풀리면 3·4번이 바로 이어지고, 조사했던 대기업 시스템과의 기능 격차(결제약속·집중도)가 사실상 해소됩니다.
- 1번을 기다리는 동안 할 수 있는 것: **2번(휴폐업 API)** 과 **5번(기준값 확정)**. 둘 다 자료 없이 진행 가능하고 효과가 즉시 나타납니다.
- 6~8번은 "있으면 좋은 참고 지표"로, 판정을 자동으로 바꾸지 않습니다. 10번은 조직 결정 사안이라 순위를 뒤에 두었습니다.
