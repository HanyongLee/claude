# 동향보고 입력 → 저장 → 채권관리 반영 프로세스 점검

점검일 2026-11-05 · 대상 버전 0.7.0-weekly. 코드 경로를 직접 추적하고 기존 자동 검증(5개 묶음 315건 통과)으로 확인한 결과입니다.

## 결론 먼저

동향보고는 **세 가지 경로** 모두 같은 저장 함수(`saveTrendReport_`)로 모이고, 제출 즉시 관리 건 상태가 자동 전이됩니다. 웹 입력은 **즉시**, 파일 제출은 **다음 정기 처리 때** 반영됩니다. 프로세스 자체는 건전하며, 보완 권장 2건(아래 ④)이 있습니다.

## 1. 세 가지 입력 경로

| 경로 | 입력자 | 반영 시점 | 증빙 |
|---|---|---|---|
| A. 웹 입력 (동향관리 화면) | 경매사·채권담당 | **즉시** | 전산 기록 |
| B. 파일 제출 (`TREND_관리건ID_날짜.json` 을 드라이브 폴더에 업로드) | 채권담당(경매사가 스냅샷에서 "파일 만들기"로 생성해 메일 전달) | **다음 정기 처리**(매일 06시) 또는 웹 "가져오기 → 지금 실행" 즉시 | 원본 파일이 관리 건에 **잠금 첨부** |
| C. 서면 체크리스트 | 경매사가 서면 체크 → 담당자가 웹 "체크리스트 입력" | **즉시** (스캔본 `CHECK_*.pdf` 는 다음 정기 처리 때 증빙 첨부) | 점수·답변이 감사 로그에 기록 |

## 2. 저장 단계에서 실제로 일어나는 일 (공통)

1. **권한 확인** — 작성 권한(trend.write) + 그 중도매인의 담당 여부. 경매사는 담당 관리 건만 쓸 수 있고, 종결된 건은 거부.
2. **입력 검증** — 제출 시 확인일·확인 방법·확인된 사실 1건 이상·결과 분류·재점검일 필수. 사실과 의견 칸 분리.
3. **잠금 안에서 저장** — `T_TREND` 에 버전으로 쌓임(임시 저장 → 제출, 제출 후 수정은 새 버전). 동시 수정은 row_version 으로 차단.
4. **신호 스냅샷 고정** — 보고서에 그 시점의 발생 신호(근거 수치 포함)를 JSON 으로 저장. 나중에 신호가 바뀌어도 "그때 무엇을 보고 판단했는지" 남음.
5. **감사 로그** — 누가 언제 무엇을 제출했는지 `L_AUDIT` 기록.

## 3. 제출 → 채권관리 자동 반영 (확인 결과 분류가 분기점)

| 확인 결과 분류 | 관리 건 상태 전이 | 함께 설정 |
|---|---|---|
| 채권 검토 필요 | → **조치진행** | 조치 기한 = 오늘 + 경매일 5일(설정 SLA_ACTION_DAYS) |
| 판정 보류(자료 부족) | 동향확인중 유지 | 재점검일 |
| 그 외(일시적 등) | → **확인완료** | 재점검일 (도래 시 홈·알림에 표시) |

전이는 모두 `T_CASE_HIST` 에 사유와 함께 기록됩니다. 반영 결과는:
- **즉시**: 웹 홈 요약 3행(이상 징후·현장 확인·조치), 담당자 업무 목록, 내비 배지, 중도매인 통합 상세 — 모두 조회 시 재계산이므로 새로고침만 하면 보입니다.
- **다음 생성 때**: 주간 스냅샷 HTML(월요일 06시 또는 수동 생성), 08시 알림 메일.
- 체크리스트 경로는 가중치 합산 점수(기준 4점, [가정])로 "연체 가능성 높음"을 **제안만** 하고, 결과 분류는 담당자가 선택합니다(설계 의도).

## 4. 경로 B(파일 제출)의 안전장치와 한계

안전장치 (모두 자동 검증으로 확인):
- 작성자(writer_id)가 **등록·사용 중 사용자**이고 작성 권한과 그 중도매인 담당 여부까지 확인. 아니면 적재 거부 → `03_가져오기_오류` 폴더 + 배치 기록.
- 같은 파일(해시 동일)을 다시 올려도 중복 적재되지 않음.
- 원본 JSON 이 관리 건 증빙(T_ATTACH, 잠금)으로 남아 뒤에 바꿀 수 없음.

**보완 권장 2건**:
1. **실패가 조용함** → **적용 완료(2026-11-05)**. 08시 알림 메일에 최근 24시간 "가져오기 실패 N건(파일명·상태)"과 확인 위치를 포함합니다. 자료 열람 권한자(채권담당·관리자)에게만 보이고, 금액 미포함 원칙은 유지합니다.
2. **최대 하루 지연** — 업로드 즉시가 아니라 다음 06시에 반영됩니다. 급한 건은 웹 "가져오기·오류 점검 → 지금 실행" 버튼으로 즉시 반영됩니다(이미 있음). 운영 안내문에 이 버튼을 명시하면 충분합니다.
