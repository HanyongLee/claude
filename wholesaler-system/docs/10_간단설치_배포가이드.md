# 간단 설치·배포 가이드 (관리자 1명이 15분, 임직원은 설치 없음)

## 한눈에

```
관리자(한 번)                              임직원(설치 없음)
─────────────────────────────────         ──────────────────────────────
① Apps Script API 켜기 (토글 1개)          카톡 공지/메일의 웹앱 링크 열기
② 새 프로젝트에 파일 2개 붙여넣기           → Google 로그인(아무 계정)
   (Install.gs, appsscript.json)           → 이메일 + 관리자가 준 접속코드 입력
③ install 실행 → 나머지 자동 다운로드       → 바로 사용
④ setupAll 실행 → 폴더·시트·가상데이터·트리거
⑤ 웹앱 배포 → URL 복사
⑥ 사용자 등록 → 접속코드 발급 → 개인 전달
```

임직원 PC에는 아무것도 설치하지 않습니다. 시스템 전체가 관리자 Google 계정 안(Apps Script + 드라이브)에서 돌고, 임직원은 웹 링크만 엽니다.

---

## 관리자 설치 (한 번)

### ① Apps Script API 켜기
https://script.google.com/home/usersettings → **Google Apps Script API** 를 **사용**으로. (설치 스크립트가 나머지 파일을 자동으로 넣기 위해 필요)

### ② 새 프로젝트에 파일 2개 붙여넣기
1. https://script.google.com → **새 프로젝트** → 이름 `중도매인 통합관리`
2. `Code.gs` 내용을 모두 지우고 **[Install.gs](../gas/Install.gs)** 내용을 붙여넣기 → 저장
3. 왼쪽 톱니(프로젝트 설정) → **"편집기에 'appsscript.json' 매니페스트 파일 표시"** 체크
4. 편집기에서 `appsscript.json` 을 열어 **[appsscript.json](../gas/appsscript.json)** 내용으로 바꾸기 → 저장

### ③ `install` 실행
상단 함수 선택에서 **install** → ▶ 실행.
처음 한 번 권한 창이 뜹니다: **권한 검토 → 계정 선택 → "고급" → "(프로젝트명)(으)로 이동" → 허용**. ("Google에서 확인하지 않은 앱" 경고는 직접 만든 스크립트라 정상입니다.)
실행 로그에 `설치 완료: 26개 파일` 이 보이면 **브라우저를 새로고침**합니다(파일 목록이 채워짐).

### ④ `setupAll` 실행
함수 선택에서 **setupAll** → ▶ 실행 (1~3분).
드라이브에 `중도매인통합관리` 폴더와 시트 6개가 생기고, 가상 중도매인 20명·25개월 자료가 적재되고, 정기 처리와 트리거(매일 06시 처리·02시 백업·08시 알림)가 설정됩니다.
실자료로 바로 운영하려면 대신 **setupAllWithoutVirtualData** 를 실행합니다.

### ⑤ 웹앱 배포
**배포 → 새 배포 → 톱니 → 웹 앱**
- 실행 사용자: **나**
- 액세스 권한: 아래 표에서 선택
- **배포** → **웹 앱 URL** 복사

| 상황 | 액세스 권한 | 설정 `AUTH_MODE` | 임직원 로그인 방식 |
|---|---|---|---|
| 혼자 시험 | 나만 | google | — |
| 회사 Google Workspace 계정이 있음 | 도메인 내 사용자 | google | 회사 Google 계정으로 자동 식별 |
| **개인 Gmail + 카톡/메일 링크 배포** | Google 계정이 있는 모든 사용자 | **code** | Google 로그인 후 이메일 + 접속코드 |

"모든 사용자(익명)"는 쓰지 않습니다. 링크가 새어 나가도 Google 로그인과 접속코드 두 단계가 남아 있어야 합니다.

### ⑥ 임직원 등록과 접속코드 발급 (code 방식)
1. 웹앱 접속(관리자 본인은 Google 계정으로 자동 식별됨) → **지표·신호 기준** → `AUTH_MODE` 를 **code** 로 변경(사유 입력)
2. **사용자·권한** → 임직원 이메일·이름·역할 등록
3. 같은 화면에서 **코드 발급** → 10자리 코드가 **한 번만** 표시됨 → **개인 카톡·문자로 전달** (단체방 금지)
4. 임직원은 링크 → Google 로그인 → 이메일 + 코드 → 사용. 12시간(가정) 후 다시 로그인. 5회 틀리면 15분 잠금.
5. 퇴직·이동 시 사용자 상태를 **중지**로 바꾸면 즉시 접속 불가(코드 재발급으로 초기화 가능).

### ⑦ 임직원에게 공유
- 카톡방 공지: 웹앱 URL + "Google 로그인 후 회사 이메일과 개인 접속코드로 로그인" 안내. **코드는 공지에 넣지 않습니다.**
- 이메일: 설정 `NOTIFY_EMAIL=예` 로 바꾸면 매일 08시 할 일이 있는 사람에게 건수·관리건ID만 담긴 요약이 갑니다(금액·상호 없음). 메일 본문에 웹앱 URL을 넣으려면 `Notify.gs` 의 안내 문구에 URL을 적습니다.

## 코드 갱신
저장소가 바뀌면 편집기에서 **update** 실행 → **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**. 자료·설정은 그대로 유지됩니다.

## 확인 방법
| 확인 | 위치 |
|---|---|
| 처리 소요 시간·오류 | 드라이브 `중도매인 통합관리_DB_LOG` → `L_JOB` 탭 |
| 누가 언제 로그인·거부됐나 | 같은 파일 `L_ACCESS` 탭 (또는 웹앱 "변경·처리 이력 → 접근 기록") |
| 시트가 외부에 공유되지 않았나 | 편집기에서 `checkSecurity` 실행 |

## 자주 막히는 지점
| 증상 | 조치 |
|---|---|
| `install` 에서 HTTP 403/PERMISSION_DENIED | ① Apps Script API 토글 확인, ② `appsscript.json` 을 바꿨는지 확인 후 다시 실행 |
| `install` 에서 HTTP 404 | 저장소 주소·브랜치가 바뀜. `Install.gs` 의 `INSTALL_SOURCE` 확인 |
| 새로고침 후에도 파일이 안 보임 | 실행 로그에 "설치 완료"가 있는지 확인. 없으면 오류 메시지대로 조치 |
| 웹앱이 "등록된 사용자가 아니거나…" | google 방식: 접속 계정이 등록되지 않음. 개인 Gmail 임직원이면 `AUTH_MODE=code` 로 바꾸고 코드 발급 |
| 로그인 화면이 안 뜨고 바로 거부 | `AUTH_MODE` 가 아직 google. 관리자가 Google 계정으로 들어가 code 로 변경 |
| 임직원이 "접속코드 로그인이 꺼져 있습니다" | 위와 같음 |

## 보안 메모 (code 방식)
- 코드는 해시만 저장되고 이력에도 남지 않습니다. 관리자도 다시 볼 수 없으며 재발급만 가능합니다.
- 세션 토큰은 브라우저에 저장됩니다. 공용 PC에서는 **로그아웃** 버튼을 쓰도록 안내하세요.
- 접속코드 방식은 Google 도메인 식별보다 약합니다. 조직 Workspace가 가능해지면 `AUTH_MODE=google` + "도메인 내 사용자" 배포로 바꾸는 것이 낫습니다.
- 실자료 투입 전 조직의 클라우드·개인정보 기준 확인은 여전히 필요합니다(설계안 Q1).
