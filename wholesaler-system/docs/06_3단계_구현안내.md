## 3. 거래·회수 매트릭스

| 요소 | 구현 |
|---|---|
| 가로축 | 최근 12개월 구매금액(부류 필터 적용), 로그 눈금 |
| 세로축 | 최근 3개월 회전율(전체 기준, 필터와 무관) |
| 색 | 전년 동기 누적 대비 증감(증가 청록·감소 주황·비교불가 회색) |
| 크기 | 현재 미수금 |
| 제외 | 신규(12개월 미만)·휴업·폐업·판정보류·회전율 산출불가·해당 부류 구매 없음 → 그래프 밖 목록 |
| 가로 경계 | 포함 점의 **당기 중앙값**(필터별) |
| 세로 경계 | `MATRIX_Y_MODE`: 전년고정(기본) → `MATRIX_Y_FIXED`. 값이 없으면 당기 중앙값으로 대체하고 표시. "기준선 재산정" 버튼이 전년도 12개 월말 회전율 중앙값의 중앙값을 계산해 출처와 함께 저장. 내부 목표값이 있으면 `목표값` 모드로 직접 입력 |
| 비연결 | 조회는 신호·관리 건을 만들거나 참조하지 않는다. 고지 문구 고정 |

경계선 방식의 장단점은 설계안 6.6을 따른다. 권장: 가로 당기 중앙값 + 세로 전년 고정(연 1회 갱신), 목표 회전율이 확정되면 세로를 목표값으로 교체.

## 4. 백테스트·그림자 운영

| 항목 | 구현 |
|---|---|
| 정답 표본 | `M_BACKTEST_TRUTH`: 중도매인코드·발생일·유형·비고. **개인정보·금액은 넣지 않는다.** 화면에서 추가·삭제(논리 삭제, 이력) |
| 실행 | 기간(기본 최근 12개월)·표본 간격(기본 5경매일)·임시 기준값(저장 안 함). 기준일마다 지표·신호를 다시 판정해 `A_BACKTEST_HIT` 저장. 시간 예산 초과 시 상태 저장 후 1분 뒤 트리거로 이어서 실행 |
| 측정 | 포착률(사안 전 90일(가정) 이내 경보), 적중률(경보 후 90일 이내 사안), 선행기간 중앙값, 주당 경보량·경매사별 주당 경보량, 규칙별 경보 수 |
| 경보 단위 | 같은 (중도매인, 규칙)의 연속 표본일을 한 경보로 묶는다(운영의 신호 구간과 같은 개념) |
| 표본 부족 | 30건 미만이면 "통계적 최적화 불가 — 업무량 상한 기준으로 정하고 운영하며 조정" 경고 |
| 그림자 집계 | 최근 8주 운영 신호의 불필요한 경보 비율 = (오탐 확정 + 일시적 변화 종결) ÷ 전체, 경매사별 주당 경보량, 규칙별 활성·해소·오탐 |

### 기준값 확정 절차 (권장)

1. 과거 사안 목록(익명 코드·시점)을 표본으로 등록한다.
2. 현재 가정값으로 백테스트 → 포착률·적중률·경매사별 주당 경보량 확인.
3. 임시 기준값으로 2~3회 반복 실행해 비교(저장되지 않음).
4. 경매사 1인당 처리 가능한 주당 경보 수를 상한으로 두고 포착률이 가장 높은 조합을 "확정"으로 저장(근거 기재).
5. 4~8주 그림자 운영(가정) → 불필요한 경보 비율 확인 후 업무 배정 시작.

## 6. 알려진 한계

1. **백테스트 실행 시간**: 기준일마다 전 중도매인 지표를 다시 계산한다. 가상 규모(20명)에서 36기준일 수 초였지만, 실자료(200명·연 60표본)에서는 수 분~수십 분이 걸릴 수 있다. 트리거로 이어서 실행되지만 일일 트리거 실행시간 할당량(개인 계정 90분)에 걸릴 수 있다 → 표본 간격을 늘리거나 기간을 줄여 실행한다.
2. **백테스트의 한도·담보는 기준일 유효 버전을 쓰지만, 데이터 품질 판정보류는 반영하지 않는다**(운영은 반영). 과거 자료 누락 구간의 신호는 과대 계산될 수 있다.
3. **표본이 적으면 포착률·적중률은 참고치**다. 가상 표본 2건으로는 기준 조정의 근거가 되지 않는다.
4. **세로축 고정 기준선은 회전율 중앙값 기반**이다. 내부 목표 회전율이 있으면 그 값을 쓰는 것이 낫다.
5. **매트릭스의 점 크기(미수금)와 색(증감률)은 보조 정보**이며 접근성 보완으로 분류 표를 함께 둔다. 색만으로 판단하지 않도록 표에 수치를 같이 표시한다.
6. **CSV 비교표 다운로드는 접근 기록을 남기지 않는다**(화면에 이미 표시된 자료). 금액 자료의 반출 통제가 필요하면 서버 생성·기록 방식으로 바꿔야 한다.
7. 회수 탭의 휴업 중도매인은 회전율이 표시된다(집계기간 중 거래가 있었기 때문). 매트릭스에서는 제외된다.

## 7. 4단계(선택) 전에 확인할 것

- 조직의 생성형 AI 사용 기준: 매뉴얼 본문을 외부 AI에 제공할 수 있는지, 중도매인 데이터는 제외해야 하는지. 승인 전까지 4단계(자유 질의응답)는 만들지 않는다.
- 서식 원본의 형식: HWP라면 자동 입력을 위해 Google 문서로 변환할지, 복사만 할지.
- 실제 환경 실행 시간: `L_JOB` 의 SIGNALS·BACKTEST 단계 소요 시간.
