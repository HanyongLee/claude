## 1. 매뉴얼 질의응답 (`Qa.gs`, 화면 "매뉴얼 질의")

외부 AI 없이 동작한다. 질문의 단어를 등록된 **상황 코드·절차·확인사항·조항·문서명·신호 이름**에서 찾아, 가장 잘 맞는 상황(최고 점수의 30% 미만은 우연 일치로 제외)의 절차를 인용과 함께 돌려준다.

| 답변 항목 | 출처 |
|---|---|
| [기준] 데이터 기준일·상태, 매뉴얼 버전 목록 | `A_STATUS`, `M_DOC_VER`(기준일에 유효한 버전) |
| 1. 확인된 상황 | 관리 건을 지정한 경우 그 건의 신호 근거 수치·동향보고 결과 (지정하지 않으면 비움) |
| 2. 추가 확인사항 | 동향보고의 추가 확인·결제계획 |
| 3·4. 절차·근거 | `M_PROCEDURE` 단계 + 문서명·버전·조항·쪽수·시행일 |
| 5. 필요 서식 | 절차에 연결된 서식(빈 서식 링크, 다운로드 기록) |
| 6. 다음 할 일 | 관리 건 상태 또는 "조치 등록/문서 등록 요청" |
| AI 답변(선택) | 사용 조건을 모두 통과했을 때만. 아니면 미사용 사유 |

규칙: 근거가 없으면 **"확인 필요"** 와 "절차를 임의로 만들지 않습니다" 문구만 표시한다. 같은 상황에 두 문서가 다르면 **"충돌"** 로 둘 다 보여 준다. 모든 질의는 접근 기록(`manual.query`)에 질문 요약·결과 상태로 남는다. 경매사는 담당 관리 건으로만 질의할 수 있다.

## 2. AI 연동 자리 (선택 기능, 기본 꺼짐)

| 설정 키 | 기본 | 의미 |
|---|---|---|
| `AI_ORG_APPROVED` | 미확인 | 조직의 외부 AI 사용 승인 결과(생성형 AI 보안서약서·클라우드 기준). **"예"가 아니면 `AI_ENABLED`를 "예"로 바꿀 수 없다.** "아니오"로 바꾸면 AI가 자동 해제된다 |
| `AI_ENABLED` | 아니오 | 질의 시 AI 호출 여부 |
| `AI_DATA_SCOPE` | 매뉴얼본문만 | AI에 보내는 범위. **중도매인 식별정보(코드·상호·대표자·연락처·보증인)는 어떤 범위에서도 보내지 않는다**(코드상 전송 대상에 없음) |
| `AI_PROVIDER_NOTE` | — | 서비스명·단가·데이터 보존 조건 메모 |
| 스크립트 속성 `AI_ENDPOINT`, `AI_API_KEY` | — | 서비스가 정해지면 소유 계정이 입력. 시트·코드에 두지 않는다 |

호출부는 `aiAdapter_` 한 곳이며, 인용할 등록 문서가 없으면 AI에 질의하지 않는다(근거 없는 답변 방지). 미구성·실패여도 검색 답변은 그대로 제공된다. AI 호출은 접근 기록(`ai.query`)에 남는다.

## 5. 알려진 한계

1. **검색은 단어 일치 기반**이다. 동의어("체납"↔"연체")나 띄어쓰기 차이는 찾지 못한다. 상황명·절차 내용에 현업 용어를 여러 표현으로 적어 두면 보완된다.
2. **AI 어댑터는 실제 서비스에 맞춰 요청·응답 형식을 조정해야 한다.** 현재는 일반적인 JSON 요청 틀이며, 서비스 선정 후 `aiAdapter_` 만 수정한다.
3. **이메일은 Google 계정 할당량**(공식 문서: 개인 100명/일, Workspace 1,500명/일)에 묶인다. 수신자 수가 그 이상이면 발송하지 않는다.
4. **알림은 하루 1회 요약**뿐이다. 즉시 알림(승인 요청 도착 등)은 없다.
5. 스냅샷 보존 규칙 때문에 45일 이전의 비월말 기준일 지표는 화면에서 다시 볼 수 없다(판단 근거 스냅샷에는 남아 있음).
